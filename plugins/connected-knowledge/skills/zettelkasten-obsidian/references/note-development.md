# Develop and reconcile ideas

Use the ontology in this skill and the existing vault conventions. These procedures adapt the supplied Zettelkasten Practice guidance; they are practical heuristics, not a validated assessment or mandatory historical method.

## Choose boundaries

Select contributions useful to a live question or future comparison: mechanisms, distinctions, conditional recommendations, counterexamples, or unresolved questions. Keep a source summary when no separate reusable idea is warranted.

Apply three tests:
- Independent use: could either part contribute to another argument without the other? Consider splitting.
- Independent revision: could evidence overturn one part while leaving the other intact? Consider splitting.
- Necessary context: would a split remove the definition, condition, mechanism, or evidence needed to interpret a claim? Retain that context with it.

Use a claim or question title, then explain reasoning, evidence, scope, and provenance. Preserve uncertainty. Remove references that depend on the surrounding chat. Do not constrain idea titles to the conversation-title word limit.

## Reconcile before adding

Search accessible notes using the proposition, alternate terms, mechanism, and source. Read plausible matches, including qualifications, before acting.

| Observed relationship | Action |
| --- | --- |
| Same proposition and scope | Add evidence to the existing idea or propose a revision. |
| Same proposition in another context | Extend it if scope stays clear; otherwise write an application as an idea note. |
| Related but distinct proposition | Keep separate and explain the connection. |
| Conflicting proposition | Preserve both; compare assumptions, scope, and evidence. |
| No useful match | Create a note without forcing links. |

Similar titles do not establish duplication. A newer claim does not automatically supersede an older one. Preserve source attribution and user interpretation. When merging is requested, retain useful qualifications and check incoming links before retiring a filename; otherwise propose the merge. If the vault is unavailable, deliver drafts and suggested connections without claiming deduplication.

## Finish the note

Check that a reader can explain the claim without the original chat, inspect its evidence, understand its limits, and identify why each link matters. Keep unresolved questions visibly provisional. An assistant-authored note is not proof that the user understands it.
