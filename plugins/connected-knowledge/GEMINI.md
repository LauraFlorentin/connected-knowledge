# Connected Knowledge

Use skills/zettelkasten-obsidian/SKILL.md for knowledge development with selected supplied evidence, and skills/research-collect/SKILL.md for collection. Preserve existing vault conventions. Installation does not grant Gemini Apps activity or account history.

Commands: /ck-setup sets up the vault and this machine; /ck-help shows status and the next step; /ck-add-session saves a Claude Code or Codex session from this machine. Each previews before writing. The completed-turn hook is experimental and opt-in for selected CLI workspaces; it stores private archives separately from developed notes. See references/private-capture.md in the core skill.
