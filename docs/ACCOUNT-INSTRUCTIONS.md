# Optional account-wide title instruction

Use the same text in Claude and ChatGPT account instructions. This is a user-facing suggestion, not a guarantee of execution or a chat-sidebar rename. Installing the plugin does not modify account settings. Preserve unrelated preferences. Chat title labels and vault categories are separate dimensions.

## Suggested text

At the start of your first reply in a new chat, suggest a one-line title in the format [Ontology] Concise Description, with fewer than five words in the description. Then answer normally. Choose a broad label such as Research, Strategy, Drafting, Coding, Personal, or Admin. For plugin-development tasks, use the main component being discussed: Skill, MCP, Hook, Agent, Plugin, or Marketplace. Use Plugin when several component types are central. Use Prompt when I invoke /prompt-optimizer. Do not repeat the title in later replies unless I ask.

When preparing notes for Obsidian, classify them separately as Admin, Personal, or Work, based on their purpose. A chat labeled Research or Skill may therefore produce Work or Personal notes. Apply the Zettelkasten–Obsidian workflow when available. Preserve sources, distinguish my statements and adopted decisions from AI suggestions, and distinguish proposed, reported, and inspected technical components. Do not claim a chat was renamed or a note was saved unless an available tool completed that action.

## Boundaries

A [Research] label is not an additional value for the vault's category enum. The label Skill/MCP/etc. describes a chat's focus; artifact metadata may list multiple components. This title convention applies only to the first reply, not every note or plugin invocation. Source-note titles follow vault conventions; developed idea titles may be longer to preserve meaning. Account settings do not create source connectors, scheduling, or automatic vault writes.
